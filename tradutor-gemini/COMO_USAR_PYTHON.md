# 🚀 COMO USAR O TRADUTOR (PYTHON)

## ✅ É SUPER FÁCIL! Apenas 3 passos:

### 1️⃣ Instalar Python

1. Vá em: **https://www.python.org/downloads/**
2. Clique no botão amarelo grande "Download Python"
3. **IMPORTANTE**: Na hora de instalar, **MARQUE A CAIXINHA** "Add Python to PATH"
4. Clique em "Install Now"
5. Aguarde instalar
6. **Reinicie o computador**

### 2️⃣ Instalar as Bibliotecas

1. Abra o **Prompt de Comando** (cmd):
   - Aperte `Windows + R`
   - Digite `cmd`
   - Aperte Enter

2. Vá até a pasta do programa:
```
cd C:\Users\alexz\Desktop\tradutor_gemini
```

3. Instale as bibliotecas (APENAS UMA VEZ):
```
pip install -r requirements.txt
```

Aguarde instalar (demora uns 2-3 minutos)

### 3️⃣ Rodar o Programa

No mesmo terminal, digite:
```
python tradutor.py
```

Quando aparecer:
```
✅ Servidor iniciando...
📝 Acesse: http://localhost:5000
```

Abra seu navegador e digite:
```
localhost:5000
```

**PRONTO! O tradutor vai abrir!** 🎉

---

## 📝 Como Usar o Tradutor

1. Cole sua **API Key do Gemini** (pegue em: https://makersuite.google.com/app/apikey)
2. Selecione os **idiomas** que você quer
3. Cole seu **roteiro** em português
4. Clique em **"Traduzir Agora"**
5. Aguarde e baixe as traduções!

## ❓ Problemas Comuns

### "python não é reconhecido"
- Você precisa instalar o Python (passo 1)
- Na instalação, marque "Add Python to PATH"
- Reinicie o computador

### "pip não é reconhecido"
- Mesma solução acima
- Python e pip vêm juntos

### "Erro na API Key"
- Verifique se copiou a chave completa
- Pegue uma nova em: https://makersuite.google.com/app/apikey

### "Porta 5000 em uso"
- Feche outros programas que possam estar usando
- Ou no código Python, mude `port=5000` para `port=5001`
